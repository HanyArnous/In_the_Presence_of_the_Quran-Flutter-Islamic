## Overview

In the Presence of the Most Merciful is a comprehensive Islamic app built with Flutter. It offers a variety of features including Quran, Hadith, Quran audio, radio, the 99 names of Allah, Duaa, and more.

## Features


تم بحمد الله إطلاق التحديث الأضخم للتطبيق، والذي يمثل نقلة نوعية في الأداء والإنتاجية الإيمانية. تم إعادة بناء أجزاء حيوية من التطبيق ليكون رفيقاً ذكياً، مخصصاً، وعالي الكفاءة.

🛠 التحديثات التقنية والبنية التحتية
ترقية المحرك (Engine Upgrade): تحديث إطار العمل من Flutter 3.19 إلى Flutter 3.38، مما يوفر استقراراً أعلى، واستهلاكاً أقل للموارد، وتوافقاً كاملاً مع أحدث الأنظمة.

التوافق مع أندرويد 14 و15: إعادة بناء نظام الإشعارات ليتوافق مع المعايير الأمنية الجديدة في Android 14 & 15، مع إدارة تصاريح الإشعارات الدقيقة لضمان عمل التنبيهات في الخلفية.

الاعتماد على Hive DB: الانتقال الشامل إلى قاعدة بيانات Hive (NoSQL)، مما أدى لسرعة فائقة في معالجة البيانات واسترجاعها لحظياً.

تنظيف المستودع (Git History): مسح ملفات الـ APK القديمة والأصول الضخمة من تاريخ المشروع لتقليص حجمه وتحسين كفاءة الرفع.

📖 تجربة القراءة والمصحف (New)
تحسينات الخطوط: إضافة خيار جعل الخط عريضاً (Bold) في صفحة المصحف لضمان راحة العين ووضوح القراءة في مختلف ظروف الإضاءة.

✨ نظام الأذكار والسبحة المطور (التحكم والمرونة)
إدارة شاملة (CRUD): إضافة أقسام أذكار جديدة، تعديل الأسماء، حذف الأقسام، أو إعادة ترتيبها بالكامل.

زر التصفير والعودة (Global Reset): زر "إعادة الضبط" لتصفير كافة العدادات والرجوع إلى الشاشة الأولى بضغطة واحدة.

التفاعل الذكي:

الانتقال التلقائي (Auto-Transition): ميزة الانتقال للذكر أو التسبيحة التالية فور الانتهاء (تعمل في الأذكار والسبحة).

التحكم الصوتي: خيار تفعيل أو كتم الصوت المرافق لكل ذكر.

نظام المفضلة: تمييز الأذكار المفضلة للوصول السريع.

📊 وحدة الإحصائيات والتحليل البياني المتقدم
رصد الأنشطة الشامل: تتبع دقيق للأذكار، التسبيح، ساعات الاستماع، وكمية القراءة.

الرسوم البيانية (Visual Charts): تمثيل إحصائياتك برسم بياني تفاعلي يوضح أنماط العبادة اليومية والأسبوعية.

المقارنة والبحث الزمني: مقارنة أداء اليوم بالأيام السابقة، مع إمكانية البحث عن الإحصائيات خلال مدة زمنية محددة.

📁 مركز التحميلات وإدارة الوسائط الذكي
البحث التلقائي (Auto-Scan): فحص ذاكرة الجهاز عند التثبيت للتعرف على الملفات المحملة سابقاً وربطها بالتطبيق.

إدارة المساحة (Storage Monitor): عرض دقيق للمساحة المستهلكة مع خيارات التشغيل أو الحذف المباشر للملفات.

🧹 جودة البيانات وإصلاحات قواعد البيانات
تنقية المحتوى: معالجة الأخطاء الإملائية وعلامات التشكيل في (أذكار الصباح والمساء) و(جوامع الدعاء).

إصلاحات تقنية: ضبط عدادات التسبيح ومشاكل الترميز (Encoding) لضمان دقة القراءة.

➕ إضافات أساسية
بوصلة القبلة: نظام دقيق لتحديد اتجاه القبلة باستخدام مستشعرات الجهاز.

تحسين تجربة المستخدم (UX): تعديلات جمالية وتسهيلات في التنقل تتناسب مع الميزات الجديدة.

🚀 Getting Started
To get started with the updated Skoon (In the Presence of the Most Merciful) app, follow these steps:

1. Clone the repository
Use the latest version (V4.6) which includes the new Hive database and advanced statistics:

Bash
git clone https://github.com/HanyArnous/In_the_Presence_of_the_Quran-Flutter-Islamic-V4.6


2. Environment Setup
Flutter Version: Ensure you are using Flutter 3.38.x or higher. This version is required for the new rendering engine (Impeller) and full Android 15 support.

Dart SDK: Automatically managed by the Flutter version above.

3. Installation
Navigate to the project directory and fetch the dependencies:

Bash
cd In_the_Presence_of_the_Quran-Flutter-Islamic-V4.6
flutter pub get
4. Run the Project
For Android: Ensure you have the latest Android SDK (API 35) installed.

Command:

Bash
flutter run
