1. نظرة عامة

تطبيق "في رحاب الرحمن" يحترم خصوصيتك. هذه السياسة توضح ما نجمعه، ولماذا، وكيف نحميه، وفق متطلبات Google Play Data Safety.

3. الأذونات المطلوبة ولماذا

  • ACCESS_FINE_LOCATION / COARSE — لتحديد القبلة وأوقات الصلاة بدقة مدينتك. يُطلب فقط عند ضغط "تفعيل أوقات الصلاة" مع حوار تفسير.
  • POST_NOTIFICATIONS — لإرسال تذكير يومي بالآيات/الأحاديث.
  • FOREGROUND_SERVICE + MEDIA_PLAYBACK — لتشغيل التلاوة في الخلفية.
  • READ_MEDIA_AUDIO / READ_EXTERNAL_STORAGE (maxSdk 32) — لقراءة التلاوات المحملة.
  • RECEIVE_BOOT_COMPLETED — لإعادة جدولة الإشعارات بعد إعادة التشغيل.
  • SYSTEM_ALERT_WINDOW (عبر flutter_overlay_window) — لعرض نافذة الذكر العائمة (اختيارية، تفعّل فقط بموافقة منفصلة).

لا نطلب MANAGE_EXTERNAL_STORAGE — نستخدم Scoped Storage عبر MediaStore.

4. مشاركة البيانات

الإحداثيات فقط تُرسل إلى https://api.aladhan.com لحساب أوقات الصلاة. لا نبيع أو نشارك أي بيانات مع معلنين. صور القراء تُجلب عبر Google Custom Search API بطلب مباشر من الجهاز.

5. التخزين المحلي والتشفير

جميع التفضيلات والإحصائيات تُحفظ محلياً في Hive على جهازك. النقل إلى api.aladhan.com و mp3quran.net يتم عبر https:// فقط (يُمنع cleartext).

6. حقوقك

يمكنك في أي وقت: إيقاف الموقع من إعدادات النظام، إيقاف الإشعارات، حذف التلاوات المحملة من مدير الملفات، أو حذف بيانات التطبيق من الإعدادات → التطبيقات → في رحاب الرحمن → التخزين → مسح البيانات.

7. الأطفال

التطبيق مناسب لجميع الأعمار ولا يجمع بيانات أطفال بشكل مستهدف.

8. التغييرات

سيتم نشر أي تحديث لهذه السياسة في نفس الرابط مع تحديث تاريخ "آخر تحديث".
