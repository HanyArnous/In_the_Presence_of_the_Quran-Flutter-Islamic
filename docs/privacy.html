1. نظرة عامة

تطبيق "في رحاب الرحمن" يحترم خصوصيتك. هذه السياسة توضح ما نجمعه، ولماذا، وكيف نحميه، وفق متطلبات Google Play Data Safety.

3. الأذونات المطلوبة ولماذا

  • ACCESS_FINE_LOCATION / COARSE — لتحديد القبلة وأوقات الصلاة بدقة مدينتك. يُطلب فقط عند ضغط "تفعيل أوقات الصلاة" مع حوار تفسير.
  • POST_NOTIFICATIONS — لإرسال تذكير يومي بالآيات/الأحاديث.
  • FOREGROUND_SERVICE + MEDIA_PLAYBACK — لتشغيل التلاوة في الخلفية.
  • READ_MEDIA_AUDIO / READ_EXTERNAL_STORAGE (maxSdk 32) — لقراءة التلاوات المحملة.
  • RECEIVE_BOOT_COMPLETED — لإعادة جدولة الإشعارات بعد إعادة التشغيل.
  • SCHEDULE_EXACT_ALARM — لضبط منبه الأذان في وقته الدقيق مع بديل غير دقيق عند رفض الإذن. لا نطلب USE_EXACT_ALARM.
  • USE_FULL_SCREEN_INTENT — لعرض شاشة الأذان كاملة عند حلول وقت الصلاة (وظيفة منبه). بدون الإذن تظهر الإشعارات كتنبيه عادي.

لا نطلب MANAGE_EXTERNAL_STORAGE ولا إعفاء البطارية (REQUEST_IGNORE_BATTERY_OPTIMIZATIONS) ولا نافذة عائمة (SYSTEM_ALERT_WINDOW) — لا توجد نافذة عائمة في التطبيق.

4. مشاركة البيانات

الإحداثيات فقط تُرسل إلى https://api.aladhan.com لحساب أوقات الصلاة. لا نبيع أو نشارك أي بيانات مع معلنين. صور القراء تُجلب عبر Google Custom Search API بطلب مباشر من الجهاز.

5. التخزين المحلي والتشفير

جميع التفضيلات والإحصائيات تُحفظ محلياً في Hive على جهازك. النقل إلى api.aladhan.com و mp3quran.net يتم عبر https:// فقط (يُمنع cleartext).

6. حقوقك

يمكنك في أي وقت: إيقاف الموقع من إعدادات النظام، إيقاف الإشعارات، حذف التلاوات المحملة من مدير الملفات، أو حذف بيانات التطبيق من الإعدادات → التطبيقات → في رحاب الرحمن → التخزين → مسح البيانات.

7. الأطفال

التطبيق مناسب لجميع الأعمار ولا يجمع بيانات أطفال بشكل مستهدف.

8. التغييرات

سيتم نشر أي تحديث لهذه السياسة في نفس الرابط مع تحديث تاريخ "آخر تحديث".

10. التراخيص وشروط الاستخدام لكل مصدر

  • mp3quran.net — ترخيص مفتوح مجاني للجميع: ينص الموقع على أن "All rights are available to everyone, and we allow any visitor or developer to copy any material or use any link". نستخدم الـ API والروابط الصوتية كما هي دون تحريف، مع الإشارة للمصدر. الشروط والتوثيق: سياسة mp3quran — توثيق الـ API.
  • AlAdhan (api.aladhan.com) — خدمة مجانية بدون مفتاح + كود GPL-3.0 + بدون ضمان: الخدمة مقدمة كما هي "WITHOUT ANY WARRANTY" وقد لا تكون المواقيت دقيقة بكل المعايير لأنها حسابية، وكود الـ API مرخص GPL-3.0. نلتزم بالاستخدام العادل مع شكر Islamic Network وفريق PrayTimes. الشروط: Credits, Terms and Conditions.
  • HadeethEnc (hadeethenc.com) — محتوى وقفي مجاني للاستخدام الدعوي والتعليمي غير التجاري مع النسبة: رسالة الموسوعة "providing them for free through all available means" كمرجع دولي مجاني. نعرض النصوص مع النسبة للموسوعة (HadeethEnc / IslamHouse) دون تحريف، وأي استخدام تجاري يتطلب إذنهم. المرجع: عن الموسوعة — صفحة المطورين.
  • Google Custom Search JSON API — رخصة Google APIs بمفتاح رسمي وحصة مجانية، وحقوق النتائج لأصحابها: الاستخدام بمفتاح API رسمي ضمن الحصة المجانية (100 طلب/يوم) ويخضع لشروط Google APIs، والصور المعروضة ملك ناشريها الأصليين وتخضع لشروطهم. المرجع: توثيق الخدمة والأسعار — سياسات Google.
  • HisnMuslim audio (hisnmuslim.com) — استخدام شخصي ودعوي غير تجاري مع النسبة، ممنوع البيع: صوتيات الأذكار للاستماع الشخصي والتعبدي فقط، ويُمنع بيعها أو استخدامها في منتجات تجارية/إعلانية دون إذن كتابي، مع النسبة لكتاب حصن المسلم وموقعه. المرجع: hisnmuslim.com.

جميع النصوص القرآنية تُعرض دون تحريف. أسماء القراء والتلاوات والترجمات والصور والعلامات ملك لأصحابها ومزوديها، وعرضها داخل التطبيق لا يعني نقل ملكيتها لنا. عند ورود أي طلب إزالة مشروع من صاحب حق سنلتزم بالمعالجة والإزالة خلال مدة معقولة عبر بريدنا أدناه.

11. إخلاء المسؤولية

  • مواقيت الصلاة والتقويم الهجري حسابية تقريبية تعتمد على إحداثيات جهازك وطريقة الحساب المختارة، وقد تختلف عن تقويم مسجدك — يرجى التحقق محلياً، خصوصاً للصيام والفجر والعشاء.
  • نصوص التفسير والحديث والترجمات والأذكار لأغراض التعليم والتدبر ولا تغني عن مراجعة العلماء والمصادر المعتمدة.
  • الخدمات الخارجية (mp3quran / AlAdhan / HadeethEnc / Google / HisnMuslim) قد تتوقف أو تتغير مؤقتاً لأسباب خارجة عن إرادتنا، وقد تتعطل ميزة مرتبطة بها لحين عودتها — لا نضمن استمرارية أي خدمة خارجية.
  • التطبيق مقدم "كما هو" (AS IS) دون أي ضمان صريح أو ضمني، وباستخدامك له تقر بذلك.

12. عدم التربح وعدم البيع والحماية القانونية

  • التطبيق مجاني 100%: لا إعلانات، ولا مشتريات داخلية، ولا تبرعات إجبارية، ولا بيع لأي بيانات.
  • لا نبيع ولا نشتري ولا نؤجر أي بيانات شخصية. الإحداثيات تُستخدم لحظياً لحساب المواقيت فقط ولا تُخزن على خوادمنا (لا توجد خوادم لنا أصلاً — كل التخزين محلي على جهازك).
  • يُحظر على الغير استخراج محتوى التطبيق أو إعادة بيعه أو تقديمه كحزمة/خدمة مدفوعة مستقلة. الاستخدام الشخصي غير التجاري مسموح.
  • أي استخدام مخالف لشروط مزودي المحتوى أعلاه يتحمل مسؤوليته مرتكبه، ويحق لنا تقييد أو إيقاف أي إساءة استخدام حفاظاً على استمرار الخدمة المجانية للجميع.
